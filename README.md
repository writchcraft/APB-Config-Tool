# APB Config Tool

> [!Important]
> # This is currently not being updated so please go to apb.gallery/config for future updates.

## Disclaimer

This project is an unofficial third-party utility.

It is **not a cheating tool** and it is **not a trojan**. APB Config Tool is only for editing configuration and localization files, including adding styled text and colour formatting.

> [!Important]
> The current public releases are **not code-signed**. I am not paying for an annual code-signing certificate for a small personal utility, so Defender may still flag unsigned builds as false positives, however it is NOT malicious at all, I have attached the source code if you want to build yourself!💜

> [!CAUTION]
> APB Config Tool has **no association at all** with **APB Reloaded**, **Little Orbit**, **GamersFirst**, or any official publisher, developer, or rights holder. It is not affiliated with, endorsed by, sponsored by, or approved by them.

<summary><strong>Premade Configs</strong></summary>

Scan premade config folders, detect editable colours and gradients, then export recoloured copies.

This is one of the more advanced options in the tool. It allows you to quickly replace colours inside an existing config, which is especially useful for configs that use gradients, as the full gradient can be detected and replaced without manually editing each value.

To use this feature, place your existing config files inside a premade config folder:

`APBConfigTool\PremadeConfigs\{ConfigName}\{ConfigFiles}`

For example, if you are using my config, you could place the files here:

`APBConfigTool\PremadeConfigs\writch\{ConfigFiles}`

Once added, the program will scan the config files and show where each colour or gradient is used. You can then easily edit the detected colours and export a recoloured copy of the config.

> [!Important]

## Notes

The application stores its working files under `Documents\APBConfigTool`.

If you want to edit a premade config, put the files in:

`C:\Users\{USER}\Documents\APBConfigTool\PremadeConfigs`

Download `APBConfigTool.exe` from the project's **Releases** page. End users do not need to download the source code unless they want to build the project themselves.

You can also check it out at [apb.gallery/config](https://apb.gallery/config)

**Please respect the work that went into this project. Do not copy, extract, or reuse parts of this program in your own tools without permission.**
